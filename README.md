## Lunear.org

### Project Summary and Motivation

`lunear.org` is meant to be a single website that hosts all of the card games that my friends and I play all the time. We often find online platforms that host these games either full of ads, complex registration hassle, unplayable on mobile, or the UI in general looks really bad. Thus instead of spending so much time searching for a website just to play a single card game is really just an inefficient use of time. Thus the motivation to write this project is to have a single always working place that offers all the card games we play all the time online, for when we are apart studying and working different areas of the world. 

This project is simply written for recreational purposes, thus please do not utilize this project as a source of gamblinhg.
